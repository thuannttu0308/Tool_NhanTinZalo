Hướng dẫn cài đặt Nhắn tin Zalo

Công cụ gửi tin nhắn Zalo theo danh sách khách hàng trong file Excel, chạy trên Google Chrome.

Trong gói này gồm:

NhanTinZalo-extension ├── NhanTinZalo thư mục cài vào Chrome ├── Huong dan cai dat.html file hướng dẫn này └── File mau khach hang.xlsx file Excel mẫu

1Giải nén

  1. Chuột phải vào file zip, chọn Extract All (Giải nén tất cả).
  2. Chọn nơi lưu cố định, ví dụ D:\NhanTinZalo-extension.
Lưu ý: không để trong thư mục Downloads và không xoá, di chuyển thư mục sau khi cài, vì Chrome chạy trực tiếp từ thư mục này.

2Cài vào Chrome

  1. Mở Chrome, gõ vào thanh địa chỉ: chrome://extensions rồi nhấn Enter.
  2. Bật Developer mode (Chế độ dành cho nhà phát triển) ở góc trên bên phải.
  3. Bấm Load unpacked (Tải tiện ích đã giải nén).
  4. Chọn thư mục NhanTinZalo nằm bên trong thư mục vừa giải nén, ví dụ D:\NhanTinZalo-extension\NhanTinZalo, rồi bấm Select Folder.
  5. Bấm biểu tượng mảnh ghép trên thanh Chrome, bấm ghim cạnh Nhắn tin Zalo để luôn hiện trên thanh công cụ.

Dùng Microsoft Edge thì làm tương tự, địa chỉ là edge://extensions.

3Đăng nhập Zalo Web

  1. Mở https://chat.zalo.me trên Chrome.
  2. Quét mã QR bằng app Zalo trên điện thoại để đăng nhập. Chỉ cần làm một lần.

4Sử dụng

  1. Bấm biểu tượng Nhắn tin Zalo trên thanh Chrome để mở công cụ.
  2. 01. Chọn file Excel: chọn file danh sách khách. Khi Chrome hỏi quyền chỉnh sửa file, bấm Cho phép.
  3. 02. Soạn tin nhắn mẫu: nhập nội dung, mỗi tin có thể có nhiều mẫu để gửi ngẫu nhiên. Bấm Chèn {Tên} để chèn tên khách vào tin nhắn.
  4. 03. Gửi tin nhắn: chỉnh thời gian nghỉ nếu cần, bấm Bắt đầu gửi.
File Excel cần có:
  • Dòng đầu tiên là tiêu đề cột.
  • Cột số điện thoại, ví dụ Số điện thoại hoặc SĐT.
  • Cột Đơn vị kinh doanh để chèn vào {Tên}.
Xem file File mau khach hang.xlsx trong gói này.

Công cụ gửi trong tab Zalo đã ghim, bạn vẫn làm việc khác bình thường trong lúc gửi. Không đóng tab Zalo khi đang gửi.

Kết quả được ghi thẳng vào file Excel, ở 2 cột Trạng thái và Nội dung tin nhắn đã gửi. Hãy đóng file trong Excel trong lúc công cụ chạy. Muốn lưu riêng một bản kết quả, bấm Xuất file Excel.

5Cập nhật phiên bản mới

Khi có bản mới, công cụ hiện thanh màu vàng "Có phiên bản mới".

  1. Bấm Cập nhật.
  2. Lần đầu tiên, Chrome yêu cầu chọn thư mục đã cài: chọn lại thư mục NhanTinZalo ở bước 2, bấm Cho phép chỉnh sửa.
  3. Công cụ tự tải bản mới và mở lại. Mẫu tin nhắn và cài đặt vẫn giữ nguyên.

Từ lần sau chỉ cần bấm Cập nhật.

Chrome hiện thông báo tắt tiện ích ở chế độ developer
Bấm đóng (X), không bấm "Tắt".
Báo "Chưa đăng nhập Zalo Web"
Đăng nhập ở tab Zalo vừa mở, rồi bấm Bắt đầu gửi lại.
Báo "File đang mở trong Excel"
Đóng file trong Excel rồi bấm Tiếp tục.
